**dhcp-snooping-82 0.3.1** brings ARP inspection to airOS 6: the package now carries an `ebt_arp.ko` built for its kernel, so the source guard binds ARP there as it does on airOS 8. Nothing changes on airOS 8.

## New

- **`ebt_arp-2.6.32.71-airos6.ko`** in the release package. airOS 6 (XW.v6.3.26) ships without `ebt_arp`, and Ubiquiti publishes no GPL archive for it. The module is built from vanilla Linux 2.6.32.71 with the OpenWrt 14.07 ar71xx toolchain (gcc 4.8 Linaro, the compiler named in the device's `/proc/version`), with the kernel adjusted where the device's structures differ from vanilla: Ubiquiti's `struct sk_buff` (`len`, `data_len`, `data` at 0x70, 0x74, 0xc4, the only fields `ebt_arp` reads) and `struct module` (OpenWrt's MIPS module relocation fields, no constructors).
- **Cross-check against the device:** `ebt_ip.ko` and `ebt_ip6.ko` built the same way match the firmware's own in vermagic, `struct module`, every load/store offset, symbols, relocation types and the match registration (`tools/check-ebt_arp.sh`). On a production station the module's rules counted the customer's ARP packets with the right sender IP and MAC and nothing for a wrong IP or MAC.
- **Loading:** `install` copies the module, `ensure`/`activate` load it with `insmod` only if the source guard is enabled, the firmware has no `ebt_arp` and its vermagic equals that of the firmware's `ebt_ip.ko`; otherwise everything stays as in 0.3.0 (ARP unchecked). `status` shows whether it is loaded.
- **Build:** `make ebt-arp` (`tools/build-ebt_arp.sh`) fetches kernel and toolchain with pinned checksums and builds the module reproducibly; `make dist` then includes it.

## Upgrade from 0.3.0

```sh
# on the PC
sha256sum -c SHA256SUMS
tar xzf dhcp-snooping-82-0.3.1-mips.tar.gz
cd dhcp-snooping-82-0.3.1
scp -O dhcp-fwd dhcp-snooping-82.sh dhcp-snooping-82.conf.example ebt_arp-2.6.32.71-airos6.ko root@DEVICE:/tmp/

# on the device
sh /tmp/dhcp-snooping-82.sh install                            # keeps your configuration
/etc/persistent/dhcp-snooping-82/dhcp-snooping-82.sh activate  # loads ebt_arp if needed, restarts the agent
sh /etc/persistent/dhcp-snooping-82/dhcp-snooping-82.sh install --save
```

On airOS 8 the module file is ignored; copying it there is not needed.
